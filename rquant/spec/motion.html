第 5 章

页面动效

动效只用来说明「什么变了」：哪个数刚变、浮层从哪来、内容换了。不做装饰。看盘页面数字多、刷新快，宁可少动。

系统设置：未开启减少动态效果

动效变量

写在 tokens.css 和 tokens.json。系统开启「减少动态效果」时，所有时长自动变成 0。

token值用在减少动态效果时
--dur-instant80ms按下反馈、开关切换、选中态0ms
--dur-fast120ms悬停、按下、退出动画、轻提示消失0ms
--dur-base180ms弹窗进入、内容淡入、展开收起0ms
--dur-slow280ms抽屉、手机底部弹层进入0ms
--dur-flash600ms行情数字闪烁褪色0ms
--dur-flash-gap1000ms同一单元格两次闪烁的最小间隔（节流）不变
--delay-skeleton300ms请求超过这个时间才显示骨架，避免一闪不变
--ease-standardcubic-bezier(0.2, 0, 0, 1)状态变化：悬停、颜色、展开收起—
--ease-entercubic-bezier(0, 0, 0, 1)进入：先快后慢，落定时轻—
--ease-exitcubic-bezier(0.4, 0, 1, 1)退出：先慢后快，干脆离开—

数字变化：行情跳动

盘中行情每 3 秒刷新。变了的数字原地替换，底色用涨跌色低透明度闪一下再褪掉，告诉你「这个刚变」。数字不做滚动计数器，不放大缩小，不弹跳。

项参数
触发条件同一单元格的新值和旧值不同。新值比旧值大闪红，小闪绿（按「这次变化」的方向，不按相对昨收）
底色涨跌色 18% 透明度（color-mix(in srgb, var(--c-up) 18%, transparent)），褪到透明
时长和曲线--dur-flash 600ms，--ease-exit
位移、缩放无。数字直接换，不滚动、不渐变数值
文字颜色按新值相对昨收重新取 .up / .down / .flat，没有过渡
节流同一单元格 1000ms（--dur-flash-gap）内最多闪一次；间隔内的更新只换数不闪
闪什么现价、涨跌幅这类直接看的数。成交额、成交量这类一直在涨的累计数只换数、不闪
一屏上限一次刷新超过 20 个单元格在变时，只闪现价列，其余只换数
减少动态效果不渐变：浅底（--c-up-weak / --c-down-weak）直接出现，1000ms 后直接去掉
读屏不播报每次跳动；只有用户聚焦的单元格变化时通过 aria-live="polite" 读新值

什么时候不用动效

情况怎么做
系统开启「减少动态效果」（prefers-reduced-motion: reduce）所有 --dur-* 变 0；闪烁改成静态浅底 1 秒；骨架去掉微光；浮层直接出现和消失
数据密集页（行情表、宏观明细）只保留行情闪烁，且按节流规则；不加任何进入动画
页面加载不做逐块淡入、逐行错开、标题飞入
非用户触发一页最多一处（行情闪烁算这一处）；不做自动轮播、呼吸灯、循环动画
图表首次绘制不做生长动画；切换周期直接重画
滚动不做视差、滚动触发动画；锚点跳转不平滑滚动

本页所有演示都跟随系统设置；上方的「模拟减少动态效果」可以不改系统设置预览降级效果。
