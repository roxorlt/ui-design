页面模板

三类页面的标准搭法，全部用组件库拼成。新页面先找最像的模板，再换内容。框里是真实页面按比例缩小，虚线框标出组件名和实测尺寸；黑框是主内容，写了首屏可见高度和占比。

套模板时的规则

规则说明
先定主数字每页一个；列表页可以是总数，详情页是现价，看板页是最能代表今天的数
区块顺序不变顶栏 → 指标区 → 主内容 → 次要内容；手机同顺序单列
页面级 CSS 只管位置栅格、区块宽高比；颜色、字号、间距全用组件和 token
首屏自查按屏效规则在 1440×900、390×844 各量一次
