rQuant 设计规范

rQuant 是给金融新手用的 A 股行情和量化看盘工具。这份规范写给做页面的人：照着它选模板、拼组件、写文案，不看旧页面也能做出和现有页面一致的新页面。

版本v1.1
日期2026-10-20
适用范围rQuant 全部页面，电脑浏览器和手机浏览器（含 iOS、安卓）
变量和样式tokens.css、tokens.json、components.css。页面只引用这三个文件，不写死色值和像素

负责人

角色负责什么
UI 设计规范负责人。维护本规范、组件库和 tokens；审批新增或修改组件；变更后逐页走查
前端开发实现。只用库里的组件和 tokens 做页面；发现缺组件先提给 UI 设计
测试验收。按本规范的屏效、状态、跨端、无障碍条目逐页检查

新增或修改组件的流程

页面里不临时造组件。库里没有或不合适，先进库再用。

  1. 任何人：产品、开发、测试提需求

    发现库里没有或不合适，提给 UI 设计。写清页面、场景，附截图。

  2. UI 设计改库

    先改组件库和 tokens，写更新记录：改了什么、为什么、影响哪些组件。按规则升版本号。

  3. UI 设计同步

    按组件使用清单列出受影响页面，把 tokens 文件和变更清单发给前端开发和测试。

  4. 前端开发实现

    引用新的 tokens 和组件样式改页面，不在页面里覆盖组件样式。

  5. UI 设计，测试配合走查

    逐页走查受影响页面，全部对上才算变更结束。

规则：页面里不临时造组件，先进库再用。页面级 CSS 只管布局（栅格、区块位置），不改组件的颜色、字号、间距。

版本号怎么升

改动升哪一位例子
大改：改 token 的值或含义、删组件、组件结构不兼容主版本 1.0 → 2.0涨跌色换值；表格默认行高从 36px 改成 40px
新增：加组件、加 token、加组件状态次版本 1.0 → 1.1新增「日期选择」组件；新增 --dur-slow
微调：不影响用法的修正修订号 1.1.0 → 1.1.1修正注释、修正某个状态的边框色

组件使用清单见 usage.md：每个组件用在哪些页面。同步时按它列受影响页面。
