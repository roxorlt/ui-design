# 门店通 v1.4

一句话：演示门店通 v1.4 新增的员工邀请/审批、离职交接、门店管理、账号绑定等关键流程的低保真原型。

## 入口

- 入口文件：`index.html`（单页应用，用地址栏 `#/...` 切换视图；首页按角色列出各页面的入口）
- 打开方式：直接用浏览器打开，或在本目录起任意静态服务后访问 `index.html`
- 数据只存在页面内存中，刷新或点顶栏「重置演示数据」即恢复初始状态；顶栏「演示角色」可切换总部 / 大区 / 店长 / 销售顾问视角
- 所有品牌、门店、人员、账号均为虚构演示数据（品牌：星驰汽车）
