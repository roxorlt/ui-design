# 门店通 v1.5

一句话：演示门店通 v1.5 的账号数据同步、合规质检与整改、素材库下发与领用、线索分配与跨店转派、转化漏斗、直播复盘、PK 复盘、积分、日报、人工接管会话等关键流程的低保真原型。

## 入口

- 入口文件：`index.html`（单页应用，用地址栏 `#/...` 切换视图；首页按角色列出各页面的入口）
- 打开方式：直接用浏览器打开，或在本目录起任意静态服务后访问 `index.html`
- 顶栏「演示角色」可切换总部 / 大区 / 店长 / 销售顾问视角；地址里带 `?role=` 时按该角色打开
- 演示中的操作保存在本浏览器里，刷新后仍在；顶栏「重置演示数据」恢复初始状态
- 收件人不是以上四个演示角色时（例如其他门店店长），在「消息 › 我发出的」里点「模拟对方查看消息」查看对方收到的内容和处理页面
- 所有品牌、门店、人员、账号均为虚构演示数据（品牌：星驰汽车）
