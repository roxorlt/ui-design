# 门店通组件用在哪

> 组件使用清单（内部），设计规范 v1.0 附表，2026-10-20。角色：总部 = 总部管理员，大区 = 华东大区经理，店长 = 门店店长（新媒体专员共用店长的手机工作台），顾问 = 销售顾问。页面一律写页面名。
> 组件样式见 [components.css](components.css)，各状态示例见 [组件状态总表](index.html)，用法见 [设计规范](../spec/components.html)。

## 基础组件

| 组件 | 用在哪些页面 | 角色 | 说明 |
|---|---|---|---|
| 按钮（主、次、幽灵、危险、加载） | 全站 | 全部 | 一个区域只放一个主按钮；危险样式只用于停用、解绑、重置这类难撤回的动作 |
| 标签页 | 消息中心（全部 / 未读 / 我发出的）、内容分发（新建发布 / 发布记录）、AI 创作 | 全部 | 顾问的消息中心没有「我发出的」 |
| 分段控件 | 驾驶舱趋势图（播放 / 线索）、发布记录日期、新建任务下发范围、线索等级 | 全部 | |
| 可横滑筛选条（.chipbar，单选） | 消息中心类型筛选（8 项）、手机工作台「消息」类型筛选 | 全部 | PC 换行、32px；手机单行横滑、44px，选中项自动滚入可视区，方向键切换 |
| 筛选芯片 | 线索页指标即筛选、消息类型筛选、手机工作台线索、新建任务类型、内容分发平台 | 全部 | 手机上有透明扩展区补足 44px |
| 指标条（主表 + 副表） | 驾驶舱、门店详情、直播详情、任务详情（总部 / 大区视角）、发布记录统计条 | 总部、大区、店长 | 每页最多一个主表；发布记录统计条兼筛选 |
| 表格 | 驾驶舱预警、门店矩阵、线索（PC）、任务门店进度表、发布记录、脚本库下发记录、PK 榜和历史战报、角色权限表 | 总部、大区、店长 | 手机宽度下在面板内横滑、首列固定 |
| 列表行 | 手机工作台三个标签页、脚本库「总部下发」、消息列表 | 店长、顾问（手机）、全部（消息） | 整行可点，≥ 56px |
| 表单（输入框、下拉、文本域、日期时间） | 新建任务、保存跟进、新建角色、内容分发发布时间 | 总部、大区、店长、顾问 | 错误写在输入框下方 |
| 轻提示（toast） | 所有写操作完成后 | 全部 | 3 秒；带操作的 6 秒 |
| 横条提示 | 全站顶部 | 全部 | 本地存储不可用、数据已更新（点此刷新）、正在完成任务 |
| 空、加载、错误 | 各列表 | 全部 | 文案见规范「空和失败状态」 |
| 进度条 | 任务卡、任务详情、门店进度表 | 总部、大区、店长 | 0 时宽度为 0 |
| 健康分 | 驾驶舱预警、门店矩阵、门店详情 | 总部、大区 | < 60 红色 |
| 元信息行（.meta） | 消息来源和时间、任务卡来源 / 周期 / 负责人、脚本车型 / 场景 / 下发人 / 时间、跟进时间线 | 全部 | 独立字段，间距 12px，不显示分隔符 |

## 业务组件

| 组件 | 页面 | 角色 |
|---|---|---|
| 顶栏铃铛（0 / 1–99 / 99+） | 所有后台页顶栏 | 全部 |
| 重置演示数据（按钮、确认框、提示） | 所有后台页顶栏；带「重置演示数据」参数的分享链接 | 全部 |
| 演示角色切换、演示数据标签 | 所有后台页顶栏 | 全部 |
| 消息行、类型标签（11 种）、来源（门店名 + 灰色角色名；总部、大区只写角色）、「去处理」 | 消息中心页、手机工作台「消息」标签页 | 全部 |
| 「我发出的」行（「催办 30 家门店，已读 1 / 30」） | 消息中心 | 总部、大区、店长（只有转交线索） |
| 内容分发页签、账号级选择、日期时间选择器 | 内容分发页 | 总部、大区、店长（本店 7 个账号） |
| 发布记录（统计条、筛选、表格、去授权 / 重新发布、空态） | 发布记录页 | 总部、大区（无按钮）、店长 |
| 今日待发布卡 | 手机工作台「我的任务」标签页 | 店长 |
| 新建任务弹层（分组多选、搜索、日期报错、加载、提交失败） | 任务中心页 | 总部、大区（范围只有华东） |
| 门店下发任务卡（进度、负责人、催办标记、去处按钮） | 任务中心页；手机工作台「我的任务」标签页（负责人是新媒体专员的） | 店长 |
| 任务详情（店长视角） | 任务详情页 | 店长 |
| 任务详情（总部 / 大区视角，任务名主标题 + 「门店进度」表格标题 + 门店进度表） | 任务详情页；任务中心页默认打开的任务详情 | 总部、大区 |
| 全店今日任务列表（完成说明用中文逗号） | 任务中心页 | 店长 |
| 「正在完成任务」横条 | AI 创作、内容分发、直播间、线索（从任务进入时） | 店长 |
| 去发视频 / 去开直播 / 去回私信 / 去跟进 | 任务卡、任务详情、全店今日任务（去跟进） | 店长 |
| 计入任务按钮 | 直播详情（从任务进入） | 店长 |
| 提醒店长按钮（预警行一次性；门店详情可重复） | 驾驶舱预警、门店详情页 | 总部、大区 |
| 提醒内容单选弹层（按钮「取消」「发送提醒」） | 门店详情 | 总部、大区 |
| 催办、一键催办（含未开始置灰） | 任务详情门店进度表 | 总部、大区 |
| 脚本库下发记录 | 脚本库列表页 | 总部、大区 |
| 脚本库总部下发列表、脚本详情 | 脚本库列表页、脚本详情页 | 店长、顾问 |
| 今日推荐脚本卡（4 种状态） | 手机工作台「我的任务」 | 店长 |
| 转交选人弹层、「转交来自 店长」标签 | 线索详情抽屉；顾问「我的线索」 | 店长（转交）、顾问（看标签） |
| 保存跟进（内容、状态下拉、时间线） | 线索详情抽屉 | 店长、顾问 |
| 最近成片卡（新生成、去分发） | AI 创作页 | 总部、大区、店长 |
| 历史战报（前 10 名带奖励） | PK 榜页 | 总部、大区 |
| 本店战报与奖励卡 | PK 榜页 | 店长 |
| 新建角色弹层、权限表（含脚本库行） | 角色与权限页 | 总部 |
| 手机工作台底部标签栏（我的任务、线索、消息，带未读数） | 手机工作台（「我的任务」「线索」「消息」三个标签页） | 店长、顾问 |
| 演示专用模块标签 | 店长驾驶舱「加入门店通前 → 现在」 | 店长 |

## 按页面查

| 页面 | 主要组件 |
|---|---|
| 驾驶舱页 | 指标条、趋势图分段控件、预警表格 + 提醒店长、健康分；店长另有全店今日任务、演示专用模块 |
| 门店矩阵、门店详情 | 表格、健康分、指标条、提醒店长 + 提醒内容弹层 |
| 线索列表页和线索详情抽屉 | 筛选芯片（指标即筛选）、表格 / 列表行、保存跟进、转交选人弹层、导出按钮（顾问默认没有） |
| AI 创作页 | 标签页、最近成片卡、「下发到门店」（总部、大区）、正在完成任务横条 |
| 脚本库列表页 | 下发记录表格 / 总部下发列表、脚本详情、空态 |
| 直播间、直播详情 | 指标条、计入任务按钮 |
| PK 榜页 | 表格、历史战报、本店战报与奖励 |
| 任务中心、任务详情 | 任务卡、新建任务弹层、指标条、门店进度表、催办、分页（每页 14 行） |
| 内容分发、发布记录 | 页签、账号级选择、日期时间选择器、统计条兼筛选、表格、去授权 / 重新发布、空态 |
| 消息中心页 | 标签页、可横滑筛选条、消息行、我发出的、空态、全部标为已读 |
| 手机工作台 | 底部标签栏、列表行、今日待发布、今日推荐脚本、下发任务卡 |
| 角色与权限页 | 权限表、新建角色弹层 |
| 全站顶栏 | 铃铛、重置演示数据、演示角色、演示数据标签、横条提示 |
