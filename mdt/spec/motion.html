第 5 章

页面动效

动效只用来说明状态变了：东西从哪来、到哪去、哪个数刚更新。不做装饰，不做入场秀。每条都有可重复播放的实物演示；系统开了「减少动态效果」时，演示同样会降级。

动效 token

时长只有 4 档，缓动只有 3 条。旧名 --m-fast、--m-base、--m-ease 保留，值和 --dur-fast、--dur-base、--ease-standard 相同，新代码用新名。

token值用在减少动效时
--dur-instant80ms按下反馈、勾选0ms
--dur-fast120ms悬停、离场、轻提示消失0ms
--dur-base200ms弹窗进场、下拉、页面内容切换、数字更替0ms
--dur-slow320ms抽屉进场、高亮淡出0ms
--dur-highlight2000ms定位高亮行停留高亮常驻，不淡出
--ease-standardcubic-bezier(.2,0,0,1)位置不变的变化：颜色、透明度—
--ease-entercubic-bezier(.05,.7,.1,1)东西进来：弹窗、抽屉、新内容—
--ease-exitcubic-bezier(.3,0,.8,.15)东西离开：关闭弹窗、收起抽屉—
--shift-sm4px新内容进场的位移0px
--shift-md8px弹窗进场的位移0px

三条原则：离场比进场快（用户已经决定关掉了）；只动透明度和位移，不动宽高和布局；一次只有一个东西在动。

系统已开「减少动态效果」时，本页演示自动按降级方式播放。

数字变化

门店通的数字变化主要是两种：指标刷新（新数据到了）和计数变化（处理掉一条，待跟进 −1）。动效只回答一个问题：哪个数刚变了。

部分时长曲线变化触发
数值更替200ms--ease-standard新数值透明度 0 → 1，原地替换，不位移数据刷新、计数变化
变化的格子停 2000ms，淡出 320ms--ease-standard底色 surface-2 → 透明数值和上次不同
芯片、角标计数200ms--ease-standard数字透明度 0 → 1，不弹跳处理了一条
数字滚动计数不做。从 0 滚到 8,456 是装饰，还会让人在滚动途中读到错的数
没变的数不动。刷新时只有变了的格子高亮

什么时候不用动效

情况做法
系统开了「减少动态效果」所有 --dur-* 变为 0、--shift-* 变为 0，状态直接切换；骨架停止光带；定位高亮常驻不淡出；滚动改为直接跳转。components.css 末尾统一处理，页面不用单独写
数据密集页（表格、看板）表格行悬停、排序、筛选结果都不做过渡，直接刷新；同一时刻最多一处在动
页面首次打开不做入场秀，不做逐块渐显
装饰不做呼吸灯、循环漂浮、数字滚动、图表生长动画、视差
高频操作勾选、切换芯片、展开树节点不超过 80ms，或者不做
长于 320ms除了骨架循环和定位高亮停留，任何过渡都不超过 320ms

判断标准只有一个：去掉这个动效，用户会不会看不懂刚才发生了什么。不会，就去掉。
